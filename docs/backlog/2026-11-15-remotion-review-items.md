# 動畫地基審查留下的小問題（2026-11-15）

動畫地基（設計見 `docs/superpowers/specs/2026-11-15-remotion-foundation-design.md`）合併前，整條分支審查了一次：沒有嚴重或重要的問題，13 條小問題。這份文件記下每一條怎麼處理。

用到的詞：

- **快取**：`work/scenes/<雜湊>.mov`，同一張卡、同樣的參數和長度，第二次輸出直接用。
- **標記色彩矩陣**：影片檔記下自己用哪一種公式把顏色換成 YUV（例如 BT.709）；沒標記的檔案，播放器和 ffmpeg 要自己猜。

## 已修

| 條目 | 問題 | 怎麼修 |
|---|---|---|
| M1 | 英文和數字的字寬算成半個字，卡片畫出來可能比動畫區寬，兩邊被切掉 | `validate` 用卡片的字型量像素寬；卡片的字級放進 `scenes/src/sizes.json`，卡片和 `validate` 讀同一份 |
| M2 | 風格沒有動畫區時，`render` 在刪掉舊成品之後才出錯 | `validate` 擋下，`render` 動手之前也拒絕 |
| M3 | node 或 npm 失敗時，錯誤訊息只寫到 `Node.js v23.7.0` 那一行 | 改成取寫出錯誤的那一行 |
| M4 | `scenes/src/` 裡的 `.DS_Store` 這類雜檔會讓每張卡重新渲染 | 隱藏檔和 `~` 結尾的備份檔不算卡片的原始碼 |
| M10 | 授權登記表說 `@remotion/effects` 沒有授權檔 | 更正：它附 `THIRD_PARTY_LICENSES.md`，部分著色器是 MIT 授權 |
| M11 | `reel` skill 有兩句只在部分情況成立 | 改寫 |
| M12 | 沒有測試確認風格或卡片原始碼改了會重新渲染 | 加測試 |

## 不改

| 條目 | 問題 | 為什麼不改 |
|---|---|---|
| M9 | 12 個 `@remotion/*` 套件的 package.json 標示 MIT，授權檢查直接放行，登記表沒有它們的列 | 符合使用者 2026-11-15 的裁定：只有標示 UNLICENSED 或沒有標示的 Remotion 套件視為 Remotion License |

## 用到再修

| 條目 | 問題 | 什麼時候修 |
|---|---|---|
| M5 | 成品已經是最新的，但快取裡的動畫影片被刪掉、node 也不在時，`render` 拒絕，而不是回「跳過」 | 有人清快取又移掉 node 時 |
| M6 | 渲染超過 1 小時被中止時，Remotion 開的瀏覽器可能還在跑（推測，沒有重現） | 真的碰到渲染超時 |
| M7 | 口播影片沒有標記色彩矩陣時，疊上去的強調色偏一點（實測 (255, 201, 0)，標記成 BT.709 的影片是 (253, 210, 0)；風格的強調色是 (255, 212, 0)） | 碰到沒標記的素材（例如重新匯出或螢幕錄影） |
| M8 | 授權檢查只在 Apple 晶片的 Mac 上通過：只有那個平台的 Remotion 元件有登記 | 要支援其他平台時 |
| M13 | 沒有測試的：兩次分開執行的渲染逐格相同、`render.mjs` 找不到瀏覽器時的訊息、清掉上次中斷留下的暫存資料夾、兩段動畫真的連著疊 | 改到相關的程式時補 |
| C1 | 風格的字型檔不是 `render` 的輸入（`style.json` 才是）：字型檔換了、其他都沒變時，`render` 跳過，成品留著舊的字幕斷行、卡片的字和卡片位置（位置看用字型量出的卡片寬度）。`pipeline/card_place.py` 的常數改了也一樣，除非調高 `render` 的格式版本（`pipeline/project.py` 的 `FORMAT_VERSIONS`）。卡片位置之前就有這個缺口，是卡片位置的審查發現的 | 字型檔會換的時候（`setup` 換字型版本，或手動改風格資料夾）；改 `card_place.py` 的常數時，同時調高格式版本 |
| C2 | 英文字母畫在卡片上時，瀏覽器會調整某些字母之間的距離（字距調整，例如 A 和 V 靠近一點），`validate` 量字寬時沒算這個：「AVAVAVAVAVAV」這種字，卡片畫出來比量的窄 9 到 23 px；中文和一般的英文字差不到 1 px。量得比畫的寬，是安全的一邊：太寬的字擋得早一點，卡片位置也照比較寬的卡片避開頭。原因推測是字距調整，還沒證實（證實的方法：卡片關掉字距調整再量一次）。再三張卡的審查發現 | 這個誤差造成問題時：量字寬時加上字距調整，或卡片關掉字距調整 |

## 示範時看到的

- 卡片固定貼著動畫區上緣的中間，test001 這支會壓到頭頂和頭髮。已修：卡片依 `faces.json` 放中間、靠左或靠右，避開講者的頭；怎麼都蓋到時，放蓋到最少的位置（設計文件第 9、12 節）。
