# Kacha 功能一覽

這一頁列出 Kacha 的功能，和你在對話裡怎麼請 Claude 做。安裝和剪片的步驟見 [README](../README.md)。

## 在對話裡怎麼說

| 你要做的事 | 在對話裡說，例如 |
|---|---|
| 剪一支新的影片 | 剪 inbox 裡的咖啡那支 |
| 接著做到一半的影片 | 繼續咖啡那支 |
| 把一段改成剪掉或留著 | 0:42 那段留著 |
| 拿掉整句 | 最後兩句拿掉 |
| 改字幕的字 | 1:48 那句字幕改成… |
| 字幕逐字變色 | 字幕改成逐字變色 |
| 放大畫面 | 0:12 那句放大 |
| 放動畫卡片 | 0:30 那句放數字卡 |
| 同意，輸出成品 | 可以 |
| 每支影片都照做 | 以後都… |

時間是審閱頁上的時間，也就是剪好的影片裡的時間。

## 粗剪

Kacha 對照你的腳本，找出可以剪的地方，標在審閱頁上。下面這幾種預設剪掉：

- 贅字：嗯、呃、欸、恩、額、誒、那個、就是。「那個」和「就是」只在腳本的那個位置沒有時才算。
- 重複的字詞和口吃，例如「我我我們」。
- 講錯重來的段落：同一句講了好幾次時，留最後一次講完的。講錯之後說了「不對」「重來」「再來一次」「再一次」「重講」「我再講一次」或「重新講」，講錯的那段和這句話一起剪掉。
- 停頓：超過 0.7 秒的停頓縮短成 0.35 秒。

下面這兩種由你決定：

- 腳本裡沒有的話：預設保留。明顯講錯的，Claude 會建議剪掉，並說明理由。
- 用詞和腳本不同的重講：Claude 看內容建議剪或留，並說明理由。

整句也可以拿掉，這一句的字幕跟著拿掉。拿掉的句子，可以在審閱頁上按「復原」，或在對話裡說。

## 字幕

- 繁體中文字幕燒進畫面，在畫面下方置中。
- 字幕的字取自你的腳本，時間對到你的聲音。
- 講的和腳本差太多的句子，字幕改用辨識出來的字。Claude 會請你檢查這些句子有沒有錯字。
- 一行最多 16 個字，英文字母和數字算半個字。一次顯示一行。
- 斷行在詞和詞之間，或在標點後面。
- 兩種樣式：一行一行出現，或逐字變色。沒有指定時，一行一行出現。
- 要改字幕的字，在審閱頁上按「改字幕」，或在對話裡說。不用改腳本。
- 腳本裡的 Markdown 記號、行首的序號和中括號裡的備註，不會出現在字幕上。

## 畫面

- 畫面不是 9:16 時，置中裁切成 9:16。
- 放大：你指定的那一句，畫面放大，以你的臉為中心。預設 1.1 倍，最多 1.2 倍。沒有指定的地方保持原尺寸。字幕的位置不變。
- 動畫卡片有三種，放在畫面上方，不會擋到字幕：
  - 重點字：一行粗體字彈出來。
  - 數字卡：大字的數字，加一行說明。
  - 清單：2 到 4 項，一項一項出現並打勾。
- 卡片上的字由 Claude 從那一句摘出來，它會先告訴你寫什麼、從幾秒到幾秒。要改卡片上的字或拿掉卡片，在對話裡說。
- 卡片上的字不能用 emoji，或其他字型畫不出來的字。

## 聲音

- 降低背景的雜音。
- 整支的音量調到社群影片常用的大小。

## 審閱和同意

審閱頁在瀏覽器裡打開，只在這台電腦上使用：

- 影片照剪好的樣子播放，剪掉的地方直接跳過，字幕疊在上面。放大也照樣播出來。
- 逐字稿上，剪掉的地方和要你決定的地方都有標記。點一下，看 Claude 的建議和理由。
- 點逐字稿上任何一個字，影片從那裡播放。
- 切換一段剪掉或保留，影片馬上照新的決定播放。
- 播到有卡片的地方，影片上方標出卡片的名稱和上面的字。動畫在成品裡才看得到。
- 看完按「同意，輸出成品」，再按「確定，輸出成品」。

你在對話裡說的改動，審閱頁幾秒內跟著更新。在對話裡回「可以」，也算同意。

不在電腦前時，可以用 Claude Code 的 [Remote Control](https://code.claude.com/docs/en/remote-control)，在手機上接著和電腦上的 Claude 對話。這時 Claude 傳一則訊息，列出要你決定的事和它的建議。它也傳分鏡稿網頁給你：這個網頁列出每一句剪成什麼樣子，在手機上也能看。回「可以」，就是同意。

同意之後又改了任何地方，要再同意一次，才會輸出新的成品。

## 輸出

- 成品 `final.mp4`：1080×1920、每秒 30 格，300 MB 以內。剪好的片長上限是 9 分 3 秒。
- 預覽版 `preview.mp4`：540×960，檔案較小，方便傳到手機上看。畫質不夠發布。
- 輸出時，硬碟要有 15 GB 以上的可用空間。

## 接續和偏好

- 每支影片有自己的專案資料夾，記著做到哪一步和你給過的意見。換了新的對話，也能接著做。
- 你說「以後都…」，Claude 會記下來，之後每一支影片都照做。
- 腳本檔或影片檔的內容改了之後，說「繼續○○那支」。Kacha 只重做受影響的步驟。
- 你的影片和腳本，Claude 只讀，不改、不搬、不刪。

## 素材

- 手機直拍的影片：畫面旋轉、HDR（高動態範圍，手機常用的拍攝格式）、不固定的幀率（每秒幾格畫面），都會自動處理。
- 影片有好幾條音軌時，用第一條。單聲道或環繞聲轉成立體聲。
- 語音辨識在這台電腦上執行，不連網。
