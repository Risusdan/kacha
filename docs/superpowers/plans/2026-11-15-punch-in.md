# Punch-in Implementation Plan

> **For agentic workers:** executed Native (Claude implements every task in this session; one reviewer on the whole branch at the end). Steps use checkbox (`- [ ]`) syntax for tracking. The user asked for small committed steps and at most one subagent at a time.

**Goal:** every cut point of the reel alternates between the base framing and a 1.1x punch-in anchored on the face; `edit.json` `punch_in` changes the scale of the shots that start in a sentence; storyboard and review page show it.

**Architecture:** pure functions in a new `pipeline/punch.py` give each segment its scale and anchor; `edit.py` gains the segment-to-sentence mapping and the `punch_in` checks; `render.py` swaps scale+crop for crop+zoompan with piecewise expressions on the output frame number; `storyboard.py` and `review_data.py` / `review.js` show the result.

**Tech Stack:** Python 3.12, pytest, ffmpeg 9.0.2 (zoompan), Node test runner for the review page.

**Spec:** `docs/superpowers/specs/2026-11-15-punch-in-design.md`

## Global Constraints

- Scales: `DEFAULT_SCALE = 1.1`, `MAX_SCALE = 1.2`, overrides from 1 to 1.2 inclusive; a shot shorter than `MIN_SHOT_S = 1.0` keeps the scale before it.
- `edit.json` `version` stays 1; `punch_in` is optional (an object: sentence id -> number); `FUTURE_KEYS` loses `punch_in`.
- Every frame is scaled once; captions are burned after the zoom.
- Example sentences in tests and docs are made up; no user material.
- TDD: each behaviour change starts with a failing test.
- Commits carry no AI attribution.

## Review Focus

- A reel with one segment (no cut point): every shot is scale 1, render graph still valid.
- A landscape source (16:9): the base window is the centre 9:16 crop; a face outside it is clamped to its edge.
- faces.json with no boxes: anchor (0.5, 0.5).
- Two segments starting in one sentence with an override: both take it.
- An odd-sized source (e.g. 1081x1921): base window has even sizes inside the frame.
